# WaveSense 3D 2.0.0

The project is renamed from **scanPHY** to **WaveSense 3D**. Functions, models and accuracy are the same as in scanPHY 1.0.0.

## What changed
- Python package and commands: `python -m wavesense serve | train | emulate | probe | info` (previously `python -m scanphy ...`).
- Dashboard branding: **WaveSense 3D**.
- Firmware: `firmware/wavesense-node`, binary `wavesense-node.bin`, serial log tag `wavesense`.
- Models: `wavesense-1node.npz`, `wavesense-2node.npz`, `wavesense-3node.npz`, `wavesense-base.npz`, plus ONNX exports. `"model": "auto"` picks the right one.
- Paper: `WaveSense3D_paper.pdf` / `.docx` with the same format and figures, renamed.

## Upgrading from scanPHY 1.0.0
1. `git pull`
2. Re-flash each board so it runs the renamed firmware. This also rewrites its WiFi settings:
   ```
   python tools/provision.py --port COM7 --node-id 1 --ssid "WIFI" --password "PASS" --target-ip <server-ip> --flash-firmware
   ```
3. Start the server: `python -m wavesense serve`
4. In `config/room.json`, set `"model": "auto"`, or click **Models -> USE AUTO**.

Boards still running scanPHY firmware keep working without re-flashing, because the radio packet format did not change.
