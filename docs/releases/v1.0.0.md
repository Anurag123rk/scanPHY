# scanPHY 1.0.0

First release of **scanPHY**: device-free WiFi CSI human sensing with ESP32-S3 boards and an NVIDIA Jetson Orin.

## Included
- **ESP32-S3 firmware** (`bootloader.bin`, `partition-table.bin`, `scanphy-node.bin`): pings the router at 50 Hz and streams CSI over UDP.
- **Edge server** (`python -m scanphy serve`): presence, still or moving activity, people counts (moving / still), zones, position and breathing rate, with a monochrome 3D dashboard on port 3000.
- **Models:** one per board count (`scanphy-1node`, `scanphy-2node`, `scanphy-3node`), a general model, and a router-distance estimator. NumPy-only inference, plus ONNX exports.
- **Training:** a physics-based multipath simulator for pre-training, auto-calibration, teach-counts recordings, and fine-tuning on the Jetson GPU.
- **Tools:** `tools/flash_nodes.py` and `tools/provision.py` for flashing and configuring the boards.
- **Paper draft** (PDF / DOCX).

## Flashing
```
python tools/provision.py --port COM7 --node-id 1 --ssid "WIFI" --password "PASS" --target-ip <server-ip> --flash-firmware
```

Accuracy figures in the paper come from simulated rooms. Real-room accuracy needs labelled recordings made with the dashboard.
